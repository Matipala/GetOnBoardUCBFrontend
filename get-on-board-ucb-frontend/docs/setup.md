# Setup

## Requisitos
- Node.js 18+

## Variables de entorno
Crea un archivo .env.local o .env basado en [GetOnBoardUCBFrontend/get-on-board-ucb-frontend/.env.example](GetOnBoardUCBFrontend/get-on-board-ucb-frontend/.env.example).

Variable principal:
- NEXT_PUBLIC_API_URL

## Instalar dependencias
```bash
npm install
```

## Ejecutar en desarrollo
```bash
npm run dev
```

## Scripts utiles
- build: `npm run build`
- start: `npm run start`
- lint: `npm run lint`
- format: `npm run format`
